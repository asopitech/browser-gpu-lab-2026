WebGPUで配列を二乗する

JavaScriptが入力データ、WGSL関数、実行命令をブラウザへ渡し、GPUで計算します。

GPUへ仕事を渡す担当

GPUAdapter
この端末で利用できるGPUの候補です。ブラウザはここから、計算を任せるGPUを選びます。
GPUDevice
選ばれたGPUを操作するための窓口です。バッファ、シェーダー、計算パイプラインを作成します。
GPUQueue
GPUへデータと命令を届ける待ち行列です。入力を書き込み、組み立てた計算を実行へ回します。

このサンプルの対応関係

WGSL関数
square が要素ごとに二乗します。
入力・出力バッファ
GPUメモリ上で [1, 2, 3, 4] と計算結果を保持します。
bind group
WGSLの @binding(0) と @binding(1) へ、それぞれのバッファを結びます。
command buffer
「計算して結果を読み戻す」命令をひとまとめにし、GPUQueue へ送ります。
